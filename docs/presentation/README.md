# WanderLust mini project presentation

Six-slide presentation for the 2025–26 third-year mini project at Shri Ram Group of Colleges, presented by Naman Sharma and Prerak under faculty guide Tanu Verma.

## Download and open

- `WanderLust_Presentation.pptx`: editable PowerPoint with six slides, speaker notes, an architecture diagram and a native data chart.
- `WanderLust_Presentation.pdf`: six-page PDF for viewing or printing.

Open a file on GitHub and choose **Download raw file**. Open the downloaded `.pptx` in Microsoft PowerPoint or LibreOffice Impress. The PDF opens in a browser or PDF reader. Cloning/pulling this repository also downloads both files.

## Contents

1. Project and student details
2. Problem, objectives and scope
3. Architecture and technology stack
4. Implemented features and interface
5. Demo dataset and search verification
6. Testing, outcomes and future scope

The deck distinguishes fictional demo data from genuine review information and implemented features from future work. Its screenshot comes from the local implementation. Speaker notes describe the scope of the local tests and limitations of live verification.
